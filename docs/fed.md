# 연방어 조어와 표준어 (규칙 v2)

구현: `fed.js`(변환기의 "연방어" 탭), Python 판 `tools/fed_v2.py`, 검사기 `tools/fed_eval/`.

## 목표
- 어감: 영어 단어를 가타카나로 옮긴 소리에 ɚ와 여러 코다로 특색을 더한 것. θ ð x는 음소로 둠.
- 경로: 영어식 변화 뒤 일본어식 음차가 오는 구조와 다르게, 수직 모음 체계에서 자음의 2차 조음이 모음을 만드는 경로(북서 코카서스어, 아일랜드어 광·세 자음 유형).
- 러시아어 모티브는 문법(격, 접두사 상, 계사 생략)에만 씀.

## 조어
- 모음: a, ā, ə, 그리고 모음 없는 음절. 강세는 어휘마다 정해짐.
- 자음: p t k q, 방출음 pʼ tʼ kʼ, 유성 b d g, s z, ʂ ʐ ʈ, θ, χ, h, m n l ɻ. 첫소리 자음은 평음·원순(Cʷ)·구개(Cʲ) 2차 조음을 가질 수 있음. 끝소리에는 j w도 옴.
- 표기(변환기 입력): 음절을 점으로 나누고 강세 음절 앞에 '. 예 kw.'lwA.dw = *kʷ.ˈlʷā.dʷ. P T K = 방출음, S Z C = ʂ ʐ ʈ, c = θ, x = χ, R = ɻ, A = ā, @ = ə.

## 음변화
1. 첫소리: 평음 p → f(모음 뒤 v), θ → ð(모음 뒤), 방출음 → 평음, q → x, ʂ ʐ → ʃ ʒ, ʈ → t, h 탈락, ɻ → ɾ.
2. 구개 치음은 파찰음·마찰음(tʲ dʲ sʲ zʲ θʲ → tʃ dʒ ʃ ʒ ʃ)이 되고 뒤 모음을 물들이지 않음.
3. 모음의 색: 원순 자음 옆 a → o, 구개 자음 옆 a → e. ā는 올라감(ā → ē, 구개 ī, 원순 ō). 강세 ə는 a·o·e, 비강세 ə는 원순 옆 u, 구개 옆 i, 평음 옆은 4번으로. ə+ɻ는 강세와 관계없이 ɚ.
4. 모음 없는 원순 자음은 개방되며 u(t d θ ð 뒤 o)를, 모음 없는 구개 자음은 i를 남김.
5. 강세 a+j → ai, a+w → au(원순 앞은 oi ou). 비강세 끝소리 j w는 i u.
6. 비강세 평음 ə: 앞 자음이 허용 끝소리면 탈락, 아니면 u(t d θ ð 뒤 o).
7. 끝소리 정리: 허용 끝소리는 남음. m → n, θ ð → t d, ʃ ʒ tʃ dʒ → s z ts z. k g x는 탈락하며 앞 모음을 늘이고(보상 장음화), p b f v는 u로 모음화. 무성 파열음·s 앞의 같은 자음은 장자음, p k는 다음 파열음에 동화. 어두의 무모음 평자음은 탈락. 끝소리는 둘 이어지지 않음.
8. ɻ 끝소리는 앞 모음을 r색으로(aɚ̯ 등), 모음이 없으면 ɚ.
9. 어말 비강세 i → iː. 같은 모음 둘(aa ee ii oo uu)은 장모음 하나로 합침. 다른 모음 연쇄는 그대로.

## 코다
- 허용: n l s z t d ts, 무성음 앞의 f v, 무성 장자음, r색(ɚ). 어말 자음군 없음.
- 근거: 접사를 뺀 영어 어근 2,633개의 끝소리는 t 20, n 14, d 12, s 9, l 8, z 4%로 허용 자음이 약 67%. k m p는 각 3~5%. k p 코다는 한국어로 적으면 ㄱ ㅂ 받침이 되어 고유어처럼 보임.

## 검사 (무작위 어근 6,000개, 형태소 기준 영어 참조)
| | 분포 차이 합 | 단어별 통과율 |
| --- | --- | --- |
| 영어 기본형 자체 | 0 | 90% |
| 이전 규칙(v1) | 1.90 | 9% |
| 규칙 v2 | 0.70 | 60% |

남은 차이: a가 많고(39% 대 30%) e가 적음(7% 대 10%), 짧은 같은 형태가 반복됨(고유 단어 84%), 2모라 단어가 많음(13% 대 9%). 가중치 조정 결과 자유 어근의 원순 자음은 드물어졌고, 원순 자음은 주로 첫머리 sʷ와 ɻ·l 앞 무모음 파열음에서 나옴.

## 문법 (형태는 v2로 다시 정함)
SOV, 후치사, 핵 후행. 주제·대격(차등 목적어 표시)·속격·사격, 복수, 과거, 존대, 완료 접두사, 분사, 부정 조동사, 문말 의문 첨사. 형용사는 상태 동사, 현재 계사 생략. 속격 조어 *-ta는 권설 조화를 따름(어간에 ʂ ʐ ʈ ɻ가 있고 그 뒤에 l이 없으면 *-ʈa).

v1의 형태소·어휘·성은 조어 체계가 바뀌어 폐기했고, 연방어 탭에서 다시 고름.
