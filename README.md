# 에클레아어 변환기 (Lévèle l'Éclêa)

판타지 세계관 **에클레아(Eklea)**의 조어 작업 도구입니다. 어머니 언어인 에클라이아어(Levela l'Eklaia) 형태를 넣으면, 정해진 음변화 규칙을 차례로 적용해 딸언어인 에클레아어의 문자형, 기본 표기(프랑스어식 철자), 발음(IPA), 한글 표기를 보여 줍니다.

```
Levela l'Eklaia  →  Lévèle l'Éclêa  [leˈvel leˈklea]
```

## 사용법

`index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 공개하면 됩니다. 설치나 서버가 필요 없습니다.

- **변환기**: 왼쪽에 에클라이아어를 입력하면 결과가 바로 나옵니다. 단어를 누르면 적용된 규칙이 순서대로 보입니다.
- **규칙 편집**: 오른쪽에서 범주와 세 단계 규칙(문자형, 기본 표기, 발음)을 고칠 수 있습니다. 고친 규칙은 그 브라우저에만 저장됩니다.
- **규칙 변경 비교**: 기본 규칙이나 저장한 기준점과 비교해 표기나 발음이 바뀐 단어, 새로 같은 발음이 된 단어를 보여 줍니다.
- **단어장**: 단어 400개가 내장되어 있습니다. 같은 발음과 유사음(한 음소 차이)을 표시하고, 단어를 추가할 때도 미리 알려 줍니다.
- **프로젝트 저장/불러오기**: 규칙과 단어장을 JSON 파일 하나로 저장하고, 다른 기기에서 불러와 합칠 수 있습니다.

## 입력 기호

| 기호 | 뜻 |
| --- | --- |
| `@` | 비음형 시작 위치 |
| `%` | 포브르어(F) 단어 |
| `&` | 학술 차용어 |
| `-` | 굴절 접두사 (표기에 하이픈. 문법 표지 `le- pe- ti- va- sa- kal-`은 모음 앞에서 자동 축약) |
| `\|` | 파생 접두사 (붙여 씀) |
| `'` | 축약된 접어 |
| `=` | 인칭 어미 |
| `^` | 접어 (따로 변화) |
| `~` | 에클라이아어 단계 합성어 |
| `·` | 에클레아어 단계 합성어 (`le-·@kiset` → l'Ègnand) |

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 변환기 전체 (규칙과 단어장 내장) |
| `data/words.json` | 단어장 원본 (내장본과 같음) |
| `rules/` | 기본 규칙 원문: 범주, 문자형, 기본 표기, 발음 |

`data/`와 `rules/`는 읽기와 비교용 사본입니다. 변환기는 `index.html`에 내장된 값을 씁니다.
