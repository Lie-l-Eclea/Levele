# 에클레아어 변환기 (Lévèle l'Éclêa)

이 도구는 우리의 어머니 언어인 에클라이아어(Levela l'Eklaia)가 어떠한 규칙과 음운 변천을 거쳐 오늘날의 에클레아어(Lévèle l'Éclêa)로 발전하였는가를 명확하게 보여 주기 위해 만들어졌습니다.

옛 에클라이아어 형태를 넣으면, 여러 세대에 걸쳐 쌓인 음변화 규칙을 차례로 적용하여 에클레아어의 문자형, 기본 표기, 발음, 음역 표기를 곧바로 재현해 냅니다.

> Levela l'Eklaia → Lévèle l'Éclêa [leˈvel leˈklea]

---

## 작업자 서문

에클라이아의 옛 땅에서 전해 내려온 문법, 그리고 훗날 포브르 민족과 만나며 일어난 수많은 음운과 통사의 재편은 오늘날 우리가 쓰는 말의 바탕이 되었습니다.

이 변환기는 동포 여러분과 후학들이 옛말의 비음 운율에서부터 오늘날 말의 끝에서 두 번째 음절 강세와 연음에 이르기까지, 우리 언어에 담긴 변화의 궤적을 직접 따라가 볼 수 있도록 엮은 연구의 결과물입니다.

작성자: 에르크페릴 위르 칼렐 칼렐뤼르 (Érquepêril Urre Calêl Calêllurre)

---

## 사용 방법

따로 설치하거나 외부와 연결할 필요 없이 `index.html` 파일 하나로 동작합니다. 파일을 열기만 하면 됩니다.

- **변환기**: 왼쪽에 에클라이아어 어근과 문법 표지를 넣으면 문자형, 기본 표기, 발음, 음역 표기의 네 가지 결과가 곧바로 나옵니다. 단어를 누르면 적용된 음변화 규칙이 차례대로 보입니다.
- **규칙 편집**: 오른쪽에서 범주와 세 단계 규칙(문자형, 기본 표기, 발음)을 직접 살피고 고칠 수 있습니다. 고친 규칙은 지금 쓰는 기기에만 보존됩니다.
- **규칙 변경 비교**: 기본 규칙이나 따로 저장해 둔 기준점과 비교하여, 표기나 발음이 달라진 단어와 새로 같은 발음이 된 단어를 찾아 줍니다.
- **어휘집**: 주요 어휘와 고유명사 400개가 들어 있습니다. 같은 발음은 뚜렷하게, 한 소리만 다른 유사음은 흐리게 표시하며, 새 어휘를 넣을 때도 미리 알려 줍니다.
- **단어 생성**: 기원(에클라이아어 고유어, 에클레아어 신어, 에냥어 차용, 에냥어 사람·민족 이름, 포브르어 차용)과 음절 수, 비음형 여부를 고르면 그 음운에 맞는 새 어휘 후보를 1개, 3개, 10개, 30개, 100개, 300개 가운데 고른 개수만큼 만들어 줍니다. 어휘집의 기존 말과 같은 발음, 유사음, 발음하기 어려운 형태를 각각 뺄 수 있고, 같은 발음을 허용하면 어느 말과 겹치는지 함께 보여 줍니다. 마음에 드는 후보는 곧바로 변환기에 넣거나 어휘집에 더할 수 있습니다.
- **보존과 이전**: 규칙과 어휘집을 프로젝트 파일 하나로 저장하고, 다른 기기에서 불러와 합칠 수 있습니다. 합칠 때는 새 어휘와 내용이 달라진 어휘의 수를 먼저 보여 줍니다.

## 입력 기호

| 기호 | 이름 | 기능 | 예 |
| --- | --- | --- | --- |
| `@` | 비음형 | 비음형의 시작 위치. 능격·완료상, 또는 비음형으로 굳은 화석 | `@kapra` → Ambre |
| `%` | 포브르어 어휘 | 포브르 민족의 말에서 들어온 어휘와 문법 요소 | `%hah` → an |
| `&` | 학술 차용어 | 후대에 옛 철자 그대로 다시 들여와 음변화를 덜 겪은 말 | `&ekolko` → écolque |
| `-` | 굴절 접두사 | 시제·법·속격 등 문법 표지의 경계. 표기에 하이픈을 남김. 문법 표지 `le- pe- ti- va- sa- kal-`은 모음 앞에서 저절로 축약됨 | `carta-` → Sarta-, `le-astel` → l'astèl |
| `\|` | 파생 접두사 | 어휘에 굳은 접두사의 경계. 표기에서 붙여 씀 | `satia\|le` → chajale |
| `'` | 굳은 축약 | 축약된 접어가 한 단어로 굳은 경계. 표기에서 아포스트로피가 사라짐 | `@v'akiscau` → Vègne |
| `=` | 인칭 어미 | 동사 인칭 어미의 경계. 어간의 비음화가 어미로 번지지 않음 | `tas=lete` → taslète |
| `^` | 접어 | 어근과 따로 음변화를 겪은 뒤 띄어 쓰는 기능어 | `sir^estai` → chir éstê |
| `~` | 옛 합성어 | 에클라이아어 시기에 합쳐져 한 단어로 음변화를 겪은 경계 | `apre~la` → aprèle |
| `·` | 새 합성어 | 각자 음변화를 마친 뒤 에클레아어 시기에 합친 경계 | `le-·@kiset` → l'Ègnand |

## 구성

```text
├── index.html        # 변환기 (음변화 엔진과 어휘집 내장)
├── data/
│   └── words.json    # 어휘집 사본
└── rules/            # 범주와 세 단계 음변화 규칙(문자형, 기본 표기, 발음)의 사본
```

`data/`와 `rules/`의 파일은 연구와 대조를 위한 사본입니다. 실제 변환은 `index.html` 안에 담긴 규칙과 어휘집으로 이루어집니다.
